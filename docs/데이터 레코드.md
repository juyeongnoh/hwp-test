# HWP의 데이터 레코드 구조

데이터 레코드는 HWP 파일에서 DocInfo와 BodyText/Section 스트림 등을 구성하는 단위이다.

데이터 레코드는 다음과 같은 구조를 갖고 있다.

- 헤더(4바이트)
  - Tag ID(10비트): 레코드가 나타내는 데이터의 종류를 나타내는 태그이다.
  - Level(10비트): 스트림 안에서의 계층 구조를 나타내는 값이다.
  - Size(12비트): 데이터 영역의 길이를 바이트 단위로 나타낸다.
- 데이터(Size에서 나타내는 값)

예외적으로 Size에서 나타낼 수 있는 최대값인 4095 이상이면 다음과 같이 추가 길이 필드를 가진다. 따라서 정확히 4095바이트를 가진다고 하더라도 추가 길이 필드를 갖게 된다.

- 헤더(4바이트)
  - Tag ID(10비트)
  - Level(10비트)
  - Size(12비트): 0xfff 고정
- 길이(4바이트)
- 데이터(가변)
